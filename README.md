# ENexam

중학교 영어 3학년 Lesson 5·6·7 듣기 수행 연습용 웹앱입니다.

- 범위: Listen & Talk 1 / 2
- 제외: Reading, Do It Yourself
- 기능: 5·6·7과 필터, 0.8×/1.0×/1.2×, 5초 되감기, 빈칸 즉시 채점, 정답 보기, 혼합 모의
- 음원: 사이트에 저장하지 않습니다. `MP3/ZIP 선택`에서 본인이 가진 NE능률 교과서 MP3 ZIP을 불러오면 브라우저 안에서만 재생됩니다.
